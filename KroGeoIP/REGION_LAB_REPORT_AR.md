# Kro GeoIP — مختبر الأدلة المستقل (20 نوفمبر 2026)

## نطاق هذا الإصدار

أداة `region_lab.py` أصلية ومستقلة، تعمل **محلياً فقط** باستخدام مكتبة Python القياسية. لا تستدعي خوادم Midasbuy، ولا تلتقط Cookies، ولا تُنفّذ تغيير منطقة، ولا تتحايل على الدفع. وظيفتها تقييم ملاحظات يدوّنها المستخدم من واجهة متجر رسمية للمقارنة بين جلسة قبل وبعد وجلسة جديدة مستقلة.

## ما الذي تأكد من المصدر؟

- **CONFIRMED:** وثائق Midasbuy تميز `user_region` (تديرها جهة اللعبة) و`shop_region` (بلد الموقع) و`payment_region` (منطقة المعاملة المستمدة من اختيار المتجر). المصدر: https://developer.midasbuy.com/guide/integration/glossary
- **CONFIRMED:** بعض الألعاب تستخدم قفل منطقة لمنع الدفع من متجر لا يوافق منطقة اللاعب. لا يجوز الاستنتاج أن كل حالة PUBG تستخدم القفل نفسه. المصدر: https://developer.midasbuy.com/guide/extensions
- **CONFIRMED:** شفرة `midasbuy-hybrid.js` في GitHub تحتوي `setCountry`، وهي تضبط حالة أداة المتصفح وتفضيلاتها، بينما `_maybeAutoSwitchCountry` تستخدم منطقة اللاعب القادمة في استجابة التحقق لضبط جلسة الأداة. هذه ليست إثباتاً لتعديل الدولة المرتبطة بحساب لاعب على الخادم. المصدر: https://github.com/medcharaf111/midasbuy-hybrid/blob/main/midasbuy-hybrid.js
- **UNVERIFIED:** وجود عملية API عامة لتغيير أهلية السعر التركي عبر Player ID فقط أو طريقة البوت الخاص التي وصفها المستخدم.

## نتائج التجارب المنفذة

جرى تشغيل اختبارات `unittest` **محلياً** على عينات مصطنعة (غير مأخوذة من Midasbuy):

1. جلسة A بعد العملية تظهر TR/TRY، لكن الجلسة الجديدة B تظهر AE/USD: يصنف المختبر النتيجة SESSION_SPECIFIC_RESULT؛ لا يثبت تعديل خادم.
2. الجلستان تعرضان TR/TRY: يصنفها CROSS_SESSION_DISPLAY_OBSERVED؛ يظل تعديل `user_region` وحق الشراء غير مثبتين.
3. جلسة واحدة فقط تُظهر TR/TRY: يصنفها SESSION_ONLY_CHANGE_OBSERVED؛ لا يزعم التحقق.
4. تظهر TR لكن العملة USD: يشير إلى تضارب البلد والعملة دون استنتاج أحقية السعر.

الأسعار والأرقام في ملفات `samples/` **أمثلة مخترعة للاختبار البرمجي** وليست أسعاراً رسمية.

## الاستخدام

```bash
python region_lab.py samples/session_specific.json
python region_lab.py samples/cross_session_display.json
python -m unittest discover -s tests -v
```

عند تسجيل قياسات حقيقية، استخدم جلسات يملك أصحابها صلاحية استخدامها، ونفس منتج UC، وسجل البلد والعملة والسعر الظاهر في الواجهة الرسمية فقط. لا تسجل بيانات الدفع أو أسماء المستخدمين أو كلمات المرور أو ملفّات الارتباط. لا تشغّل أي تغيير على حسابات الآخرين ولا تحاول تجاوز رفض Midasbuy للأهلية.
